# Customer Communications

クライアント(さくら株式会社・秋元様)へのご報告資料・打ち合わせ記録の保管場所。

## ファイル命名規則

`YYYY-MM-DD_<種別>.md` 形式:

- `*_progress-report.md` — 詳細な進捗報告書
- `*_progress-summary-1page.md` — 1 枚要約版(打ち合わせ冒頭で配布)
- `*_questions-for-client.md` — クライアントご記入用の質問票
- `*_meeting-notes.md` — 打ち合わせメモ
- `*_proposal-*.md` — 提案書類

## 機微情報の取り扱い

このフォルダの資料には以下を **含めない**:
- API キー / トークン
- パスワード
- 個人情報(クライアント名以外)
- ログイン情報(別途メッセンジャー等で送付)
