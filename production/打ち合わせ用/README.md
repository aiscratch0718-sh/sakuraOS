# 打ち合わせ用 — クライアント向け資料

クライアント(さくら株式会社・秋元様)との打ち合わせで使う資料の保管場所です。

## このフォルダの目的

- 進捗報告書(詳細版・1 枚版)
- ご確認いただきたい事項のまとめ(質問票)
- 打ち合わせ議事メモ
- ご提案資料

## ファイル命名規則

`YYYY-MM-DD_<種別>.<拡張子>` 形式:

| パターン | 内容 |
|---|---|
| `*_progress-report.{md,docx}` | 詳細な進捗報告書 |
| `*_progress-summary-1page.{md,docx}` | 1 枚要約版(打ち合わせ冒頭で配布) |
| `*_questions-for-client.{md,docx}` | クライアントご記入用の質問票 |
| `*_meeting-notes.{md,docx}` | 打ち合わせメモ・議事録 |
| `*_proposal-*.{md,docx}` | ご提案書類 |

## ファイル形式について

- **`.md`(Markdown)** — Claude が編集する元データ。GitHub 上で読みやすい
- **`.docx`(Word)** — クライアントにお渡しする最終形態。エクスプローラーから直接開ける
- 両方を併存させ、Markdown 修正後に Word を再生成する運用

### Word ファイルの再生成

```bash
node tools/gen_progress_docx.js
```

## 機微情報の取り扱い

このフォルダの資料には以下を **含めない**:

- API キー / トークン / 認証情報
- ログイン用パスワード
- 個人情報(クライアント代表者名以外)
- 本番環境の URL(別途メッセンジャーで送付)
- 売上額・財務数値の生データ(集計値のみに留める)
